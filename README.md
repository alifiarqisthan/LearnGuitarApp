# Chordroom

A personal guitar-learning app for beginner-friendly daily practice.

- A 30-day starter plan and a 90-day learning path, with a daily 20-minute routine and weekly goals.
- An eight-part beginner fundamentals course, with your place saved locally.
- Chord-change drills, rhythm practice, open-string note recall, and beginner fingerstyle exercises.
- A song shelf of 25 songs from Very easy to Very hard, including Hey Jude. Pick a song to add it to My songs and practise its editable chord chart, transpose, and recall mode.
- A metronome, timed practice rounds, self-counted results, and locally saved progress.

## Run on Windows

Double-click **Start Chordroom.bat**. It starts the local app and opens it in your default browser. Node.js must be installed. To run from a terminal instead, open this folder and run `npm start`, then visit http://127.0.0.1:4173/.

Practice scores are self-reported: this version does not listen to or automatically grade the guitar. Data is stored in this browser on this computer. This is a local browser app with a Windows launcher, not a standalone `.exe` installer.
